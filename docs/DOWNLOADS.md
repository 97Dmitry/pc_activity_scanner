# PC Activity Scanner — запуск готовой программы

Это комплект готовой программы. Rust и компилятор для запуска не требуются.
В папке находятся бинарник, LICENSE и RELEASE_NOTES.md с изменениями и
ограничениями версии.

## Windows 11 x64

Распакуйте ZIP целиком и запустите `pc_activity_scanner.exe` двойным кликом.
Программа портативная; установка и запуск от администратора не нужны.
Бинарник не подписан, поэтому Windows может показать неизвестного издателя.

## Linux x86_64

Распакуйте tar.gz, откройте терминал в полученной папке и запустите:

```bash
./pc-activity-scanner
```

Нужен графический сеанс X11/Wayland. Для Ubuntu/Kubuntu установите библиотеки:

```bash
sudo apt update
sudo apt install libx11-6 libxcb-render0 libxcb-shape0 libxcb-xfixes0 libxkbcommon0 libwayland-client0 libgl1 libegl1 libxcursor1 libxi6 libxrandr2 libxkbcommon-x11-0
```

### Трафик отдельных процессов на Linux

Эта функция необязательна. CPU/RAM и общий трафик работают без неё.
Для NetHogs нужен установленный системный бинарник с защищёнными правами:

```bash
sudo apt install nethogs policykit-1
sudo install -D -o root -g root -m 0755 ./pc-activity-scanner /usr/local/bin/pc-activity-scanner
pc-activity-scanner
```

Затем включите «Трафик по процессам» в настройках. Системный диалог Polkit
ожидаем; GUI продолжает работать без повышения привилегий. Запускать весь
интерфейс через sudo не нужно.

## Использование

Поиск принимает имя, PID и путь. Заголовки сортируют таблицу. «GPU и итоги
трафика» показывает дополнительные столбцы. «Экспорт CSV» сохраняет видимые
строки в Downloads. Неизвестные метрики отображаются как `—`.
«Пауза» приостанавливает обновление процессов. «Выход» завершает программу;
закрытие окна может скрывать её в трей, если он доступен.

## История приложений

«Обзор» объединяет текущее состояние и сохранённые графики. В «Истории» можно
выбрать 1/6/12/24 часа, найти приложение и открыть его средние/пиковые показатели.
«Сравнение» накладывает графики до четырёх приложений. Исторический CSV
экспортируется отдельно от текущей таблицы.

История начинает накапливаться после запуска программы и сохраняется между
запусками. По умолчанию хранятся 24 часа агрегатов; в настройках можно выбрать
1/3/7 дней, отключить запись и очистить историю с подтверждением. Записываются
локальные имена, пути и показатели ресурсов. Для получения 12 часов наблюдений
программа должна проработать соответствующее время; остановки остаются пробелами.

## Проверка файлов

Скачайте `SHA256SUMS.txt` из того же релиза рядом с архивом. В Linux можно
проверить конкретный скачанный файл командой `sha256sum имя-файла` и сравнить
значение с соответствующей строкой манифеста. В PowerShell используйте
`Get-FileHash имя-файла -Algorithm SHA256`. Контрольная сумма проверяет целостность;
она не заменяет цифровую подпись издателя.
