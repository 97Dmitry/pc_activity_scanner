# PC Activity Scanner 0.5.0

## Интерфейс для ежедневной работы

- Процент CPU-вклада вынесен рядом со шкалой: текст не сливается с заливкой.
- На основных экранах появилась заметная карточка «Полный мониторинг»: сбор сети
  включается здесь, с понятным объяснением запроса Windows, а не прячется в настройках.
- Выбор пользователя сохраняется. При ошибке доступен повтор, при отказе — обычные
  CPU/RAM и общий трафик. Неизмеренный трафик приложений не подменяется общим.
- Настройки сокращены до действий; версии, пути, источники метрик и сырые ошибки
  доступны в отдельном окне «Диагностика» с копированием сведений.
- Ошибки истории, экспорта и сохранения настроек показываются понятным сообщением
  и действием «Подробнее».

## Автозапуск Windows

- Обычный запуск при входе настраивается переключателем с проверкой результата.
- Повышенный режим по явной кнопке подготавливает защищённую копию программы и
  запрашивает разрешение Windows; вручную переносить EXE в Program Files не нужно.
- Ошибка или отмена не выключает элементы управления и не выдаётся за успешное
  применение. Показаны подтверждённое состояние, повтор и проверка состояния.
- Сырой CLIXML больше не попадает в обычный интерфейс.
- Защищённые копии адресуются по SHA256, чтобы обновление не пыталось заменить
  запущенный EXE. Старые копии сохраняются; это добавляет размер одной программы
  на обновлённую версию. Подпись/автоматическое обновление не добавлены.

## Скачать

- Windows x64: `pc_activity_scanner-v0.5.0-windows-x86_64.exe` или ZIP.
- Linux x86_64: `pc_activity_scanner-v0.5.0-linux-x86_64` или tar.gz.
- SHA256SUMS.txt проверяет оба архива и оба отдельных бинарника.

## Проверка и ограничения

Rust formatting, Clippy, unit tests, release builds и существующий ETW TCP/UDP
IPv4/IPv6 smoke выполняются в Windows/Linux CI. Специальные opt-in тесты на
одноразовой Windows-машине проверяют создание/удаление уникальной задачи и
защищённую установку; обычный запуск тестов не меняет автозапуск компьютера.
Linux-интерфейс проверяется под Xvfb. Реальное подтверждение UAC, вход в Windows,
DPI и трей остаются отдельной ручной приёмкой.

Сбор истории не восстанавливает старые сетевые данные. Сетевой сбор требует
разрешения Windows; оно не обходится. Бинарники не подписаны.
