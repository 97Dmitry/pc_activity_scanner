# PC Activity Scanner 0.3.1

## Читаемость интерфейса

- Основной текст и кнопки увеличены с 13 до 15; подписи графиков — с 10 до 12.
- Вспомогательный текст — 13, числовые значения в таблицах — 14.
- Повышен контраст обычного и вторичного текста, границ элементов и чередующихся строк.
- Увеличены строки таблиц и отступы осей графиков; линии графиков стали толще.

## Скачать

- Windows x64: `pc_activity_scanner-v0.3.1-windows-x86_64.exe` или ZIP.
- Linux x86_64: `pc_activity_scanner-v0.3.1-linux-x86_64` или tar.gz.
- Архивы содержат инструкцию, лицензию и описание релиза. Контрольные суммы — `SHA256SUMS.txt`.

## Проверка и ограничения

Rust formatting, Clippy, unit tests and release builds run on Windows and Linux in CI.
Linux GUI startup/resizing is checked under Xvfb. This does not establish manual
Windows desktop acceptance. Binaries are unsigned. Metric availability and history
storage are unchanged; see [history documentation](../HISTORY.md).
