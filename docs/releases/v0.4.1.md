# PC Activity Scanner 0.4.1

## Читаемость интерфейса

- Основной текст и кнопки увеличены с 13 до 15; подписи графиков — с 10 до 14.
- Вспомогательный текст — 13, числовые значения в таблицах — 14.
- Повышен контраст обычного и вторичного текста, границ элементов и чередующихся строк.
- Увеличены строки таблиц и отступы осей графиков; линии графиков стали толще.

## Графики и обновления

- Устранено мигание графиков при фоновом обновлении истории: последняя выборка остаётся видимой до прихода новой.
- Короткие периоды 5/15/30 минут дополняют 1/6/12/24 часа; начальный диапазон — 15 минут.
- Выделение диапазона мышью приближает графики; общий период сохраняется для рейтинга и экспорта.
- Оси используют адаптивное число подписей, чтобы они не перекрывались в узком окне.
- Колонка имени процесса пересчитывается при уменьшении окна и не вытесняет остальные показатели.

## Windows: сеть приложений

- Добавлен отдельный ETW TCP/UDP-сборщик с запросом UAC, GUI по умолчанию работает без повышения.
- Трафик по приложениям доступен в таблице, истории и сравнении после включения в настройках.
- Ошибки, отказ в UAC и потерянные события не подменяются нулями; прошлый трафик восстановить нельзя.

## Windows: автозапуск

- Настройка запуска при входе в Windows через Планировщик заданий, с чтением фактического состояния.
- Можно выбрать обычный или повышенный режим. При применении нужен UAC.
- Повышенный режим требует защищённой копии в Program Files; для Downloads доступен обычный режим.
- После переноса приложения задача помечается для ремонта; повторное применение обновляет путь.

## Иконки

- Новый авторский знак монитора с графиком; отдельная упрощённая версия для трея.
- Значок встроен в Windows EXE (16–256 пикселей), окно и панель задач.
- Установщик Linux размещает SVG/PNG в теме иконок.

## Скачать

- Windows x64: `pc_activity_scanner-v0.4.1-windows-x86_64.exe` или ZIP.
- Linux x86_64: `pc_activity_scanner-v0.4.1-linux-x86_64` или tar.gz.

## Проверка доставки событий

Проверка Windows теперь дожидается полного счётчика ETW в пределах явного срока,
вместо фиксированной паузы. Асинхронная доставка не считается завершённой по
таймеру; неполные байты по-прежнему приводят к ошибке. Сетевой backend и учёт
байтов этим исправлением не ослаблены.

## Проверка и ограничения

Проверки Rust (formatting, Clippy, unit tests, release build) выполняются в CI
Windows/Linux. Windows CI отдельно проверяет реальный ETW-сбор TCP/UDP по IPv4/IPv6
через production helper; Linux — запуск и изменение размера окна под Xvfb.

Реальные UAC, вход/выход Windows, Explorer/tray и DPI остаются ручной приёмкой;
проверки CI не заменяют её. GPU по приложениям в Windows пока недоступен.
Бинарники не подписаны. Принудительное уничтожение повышенного ETW-helper может
оставить его сессию до перезагрузки; обычное отключение/выход выполняют очистку.
