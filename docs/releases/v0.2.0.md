## PC Activity Scanner 0.2.0

Версионный релиз локального монитора процессов для Windows 11 x64 и Linux x86_64.

### Что изменилось

- Переработан интерфейс: компактная таблица, переключение GPU и сессионных итогов,
  сворачиваемый график, состояния паузы и пустого поиска, копирование имени/PID/пути.
- Поиск по PID и пути работает при группировке процессов.
- Исправлены потеря промежуточных кадров NetHogs и всплеск общей скорости после паузы.
- Выключение NetHogs больше не задерживает окно; сообщения старой сессии не меняют новую.
- Настройки заменяются атомарно; ошибка записи не удаляет предыдущий файл.
- Кеш строк устраняет повторную фильтрацию и сортировку неизменных данных.
- Сборщик больше не запрашивает ненужные сведения о потоках и дисковом I/O.

### Что скачать

В разделе **Assets**:

| Система | Готовый комплект | Отдельный исполняемый файл |
|---|---|---|
| Windows 11 x64 | `pc-activity-scanner-v0.2.0-windows-x86_64.zip` | `pc_activity_scanner-v0.2.0-windows-x86_64.exe` |
| Linux x86_64 | `pc-activity-scanner-v0.2.0-linux-x86_64.tar.gz` | `pc_activity_scanner-v0.2.0-linux-x86_64` |

Архивы содержат программу, README, лицензию и описание релиза.
Rust и инструменты разработки для запуска не нужны. Windows: распакуйте ZIP и
запустите `pc_activity_scanner.exe`. Linux: распакуйте tar.gz и запустите
`./pc-activity-scanner` в графическом сеансе; зависимости перечислены в README.
Не запускайте интерфейс через sudo.

`SHA256SUMS.txt` содержит SHA-256 обоих архивов и отдельных бинарников.
**Source code (zip/tar.gz)** — исходники, автоматически добавляемые GitHub;
для обычного запуска выбирайте готовые файлы из таблицы выше.

### Поддержка и ограничения

- На обеих ОС доступны CPU/RAM и общая скорость сети.
- Трафик по процессам доступен на Linux через установленный NetHogs и Polkit;
  GPU/VRAM по PID зависят от Linux-драйвера. На Windows эти метрики пока `—`.
- Сессионный трафик — оценка; длительная пауза может переполнить ограниченную
  очередь, что отображается в статусе.
- Бинарники не подписаны. ОС может показать предупреждение о неизвестном издателе.
- CI проверяет форматирование, Clippy, unit-тесты и release-сборки на Windows/Linux,
  а также запуск окна в Linux Xvfb. Ручная проверка реальных Windows/Wayland,
  трея, GPU и диалогов Polkit ещё не завершена; этот релиз не является
  сертифицированной production-сборкой.
