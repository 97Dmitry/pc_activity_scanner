# PC Activity Scanner 0.6.0

## Нагрузка на компьютер

- Скорости I/O процессов и активность отдельных накопителей, сортировка,
  история и CSV. Windows Process I/O включает также другие устройства и сеть:
  он показан отдельно от физической активности диска.
- GPU процессов в Windows через PDH: максимум доступной загрузки движка среди
  адаптеров, отдельные dedicated/shared GPU memory. Проценты разных движков
  не складываются. Поддерживаемые показатели записываются в историю и CSV.
- Раскрываемые группы приложений и отдельный режим дерева родства. Стрелка
  раскрытия теперь рисуется средствами egui: перед именем больше не нужен
  отсутствующий в шрифте символ, который отображался квадратом.
- Подробная память: resident, private commit, Linux file/shmem RSS и swap,
  доступные ошибки страниц. Неизвестные CPU/RAM показаны как «—».
- TCP/UDP, IPv4/IPv6 выбранного процесса: адреса, порты и состояние TCP.
  Автоматических DNS-запросов и сбора содержимого пакетов нет.
- Компактная сетка загрузки логических CPU. CPU процессов по-прежнему
  нормализован по всем логическим процессорам хоста.
- Именованные температурные датчики и достоверные thermal-признаки там,
  где доступны источники. ACPI-зона не выдаётся за температуру CPU.
- Настраиваемые правила длительной нагрузки и расхода/роста памяти:
  длительность, cooldown, журнал и уведомления в приложении. Правила выключены
  по умолчанию; системная доставка включается отдельно. Пропуски, паузы и
  новые времена жизни процессов сбрасывают ожидание события.

Сохранены системный clipboard, группировка по умолчанию и native CPU/RAM
виртуальных машин Windows без администратора. `vmmemWSL` отображается как
`WSL2 (vmmemWSL)`. GUI не управляет процессами и не меняет настройки системы
ради измерений.

История мигрирует в схему 4 кодом приложения с отдельным покрытием метрик.
Существующие данные сохраняются. Срок хранения по умолчанию 24 часа и лимит
512 МиБ не увеличены. Новые метрики собираются вне GUI через ограниченные
очереди; соединения, датчики и журнал событий не добавляют постоянную историю.

## Проверка и ограничения

До подготовки релиза пройдены 210 Linux-тестов, 194 нативных Windows GNU-теста
и 5 тестов упаковки, Clippy и release builds обеих платформ. Реальные API
проверены в WSL2 и Windows: I/O, PDH PhysicalDisk/GPU, native память/VM,
соединения, 16 логических CPU, ACPI/NVIDIA и контролируемое событие памяти.
Подробности и границы доказательств — в `docs/RESOURCE_VERIFICATION.md` репозитория.

PR и тег дополнительно проходят Windows/Linux CI: форматирование, Clippy,
тесты, release builds, Linux Xvfb и Windows ETW smoke. Изменяющие автозапуск
тесты выполняются только в отдельном opt-in режиме одноразового CI runner.
Локальная проверка не заменяет CI или ручную приёмку GUI.

У Windows нет универсального источника температуры CPU и троттлинга без
дополнительных драйверов. Физический Linux с hwmon/DRM, реальный thermal
throttling, многочасовой hardware soak и many-core оборудование не проверены.
Драйверы не устанавливаются. GPU memory отражает отчёт WDDM; её рост сам по
себе не доказывает утечку. Недоступные показатели остаются неизвестными.

Системные уведомления зависят от политики рабочего стола; на Linux нужен
`notify-send`. Уже принятый ОС запрос невозможно гарантированно отозвать.
Windows CLI-помощник включается в private Job сразу после запуска: остаётся
короткое окно аварийного выхода между spawn и назначением Job. Бинарники
не подписаны. Визуальная приёмка нового индикатора, DPI, tray, clipboard и
Polkit остаётся ручной проверкой.
